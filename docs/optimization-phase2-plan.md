# 第二批：寄存器分配

基线更正：早先 15/15 Accepted、11 项 100%、4 项 ≥80% 的表格属于完整旧版，不能证明重写第一批的平台性能。测试源码快照 tests/.phase2-work/phase1-src 仅代表重写第一批。当前提交包已确认正确，但缺少完整旧版的高级优化，后续须对照旧版验收。

约束：生产改动只在 optimize 和 backend。不修改 frontend、midend、输入运行库和延迟槽。保持 -Dcompiler.optimize=off 原版行为；新增 -Dcompiler.registers=off 仅关闭寄存器分配，便于独立比较。

设计：对现有 SSA 临时值、函数参数与地址不逃逸的局部标量做活跃分析和干涉图着色。局部标量的 load 是使用，store 是定义，不需要引入 Phi。固定保留 t0–t3 作后端临时寄存器；其余 t 寄存器只用于不跨调用的值，s 寄存器用于跨调用存活的值，实际使用的 s 寄存器由被调用者保存和恢复。着色失败保留栈槽。循环深度提高分配优先级；低频值避免为保存寄存器付出不必要的开销。
