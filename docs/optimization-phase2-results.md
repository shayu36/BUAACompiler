## 代码改动

相对第一批仅新增/修改四个生产文件，合计生产 Java 文件为 125 个：

- `src/optimize/Liveness.java`：块级与指令级 Use/Def、In/Out 分析；局部标量的 load 作为使用、store 作为定义。
- `src/optimize/RegisterAllocation.java`：自然循环权重、干涉图和确定性的乐观着色；处理 SSA 临时值、参数与非逃逸局部标量。
- `src/backend/BackEnd.java`：直接读取已分配寄存器、写回结果、处理局部标量寄存器、初始化使用到的参数、保存及恢复实际使用的保存寄存器。
- `src/backend/MipsFrame.java`：为溢出值和保存寄存器安排栈槽，按新栈帧大小计算传入参数偏移。

`$t0`–`$t3` 固定用于后端临时计算；`$t4`–`$t9` 用于不跨调用存活的值；跨调用值使用 `$s0`–`$s7` 或栈。寄存器不足时保留原有访存路径。冷值会考虑保存/恢复开销，未使用的参数不装入寄存器。带符号窄整数运算先复制到临时寄存器再扩展，避免破坏仍活跃的原值。

前端、中端、Compiler、utils、输入运行库和延迟槽实现均未修改。本批没有加入常量乘除、函数内联或循环展开，便于平台反馈归因。

# 关闭全部优化

python D:\mycomplier\tests\verify_phase2_ir.py --classes D:\mycomplier\tests\.phase2-work\final\classes
